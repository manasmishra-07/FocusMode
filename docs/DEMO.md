# Four-minute demo script

Prepare: run API and client, log in as student, open the visible companion. For a real demonstration, use a controlled desktop with a disposable application and review the Windows manual checks first. If using mock, say clearly: **this is simulation; no applications are changed**.

**0:00–0:30 — Problem and architecture**

“Browsers cannot minimize other applications. React gives the controls, Django stores accounts and history, and a visible Python companion owns the OS actions. We intentionally substituted Django/SQLite for MERN, subject to teacher acceptance.” Show the overview and connection badge.

**0:30–1:10 — Pairing and consent**

Show the companion's short-lived code. Pair from My devices. Explain that the agent verifies the JWT identity through Django and stores its credential with Windows DPAPI. Open Allowed apps: built-in browsers/agent/system entries cannot be removed; add Code.exe if desired.

**1:10–2:10 — The focus flow**

Choose one minute, open the confirmation and read the preserved-app summary. Confirm. Show the active countdown only after agent acknowledgement. In a reviewed real-mode demo, show the disposable app minimized and browser/agent preserved. Close or reload the dashboard to explain independent timing. Show the agent-side End Focus escape hatch. Do not demonstrate uncontrolled minimization on someone else's desktop.

**2:10–2:45 — End and history**

End locally or let the minute expire. Show restoration (real mode) and the persisted session, actual vs planned duration, status and simulation label when relevant. Explain that only the agent uploads events and UUIDs prevent duplicate history on retries.

**2:45–3:25 — Routines and insight**

Show a weekday schedule form, device selection, timezone, opt-in and 15-second heads-up. Explain missed runs are recorded, never started late. Show real-session-only metrics, seven-day chart, streak and completion-rate definitions. Do not invent completed data if none exists.

**3:25–4:00 — Admin, safety and honest limits**

Use the development admin login to show users, presets, aggregate usage and download configuration. Mention native safe-window verification, tests, Windows compatibility checks still needed, documented macOS approach, and unverified hosted HTTPS connectivity. Open AGENT_WALKTHROUGH.md for the viva. A recording, team attribution and any deployment link remain submission tasks.
